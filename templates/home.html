🤖 The Robotiator Files

Team 888 Workshop Attendance System

Welcome to the Robotiators Attendance System. Built to last with zero maintenance required.

🔑 How to Access

  1. Registration: Go to the Registration page. Enter your full name and create a PIN (4+ digits).
  2. Logging: Visit the Logging page to log in/out using your PIN. Enter your PIN and submit to toggle your status.
  3. Admin: Access administrative tools using the Admin page. Use PIN RobotiatorFiles888 for system overrides.

📊 Tracking Your Hours

  • Leaderboard: See who has the most hours in the current season.
  • Statistics: View total progress towards seasonal goals.
  • Export: Download leaderboard data as CSV from the Admin page.

🛡️ System Features

  • Auto-Logout: Automatic logout at midnight with 30-minute cap from login time.
  • Backups: Every event logged in database. Data easily exportable to CSV.
  • Reliability: No maintenance required. Just log in and out!

🚀 Quick Start

New member? Follow these steps:

  1. Click Registration button in the navbar
  2. Enter your name and create a 4+ digit PIN
  3. Click Logging to log in with your PIN
  4. Click again to log out when you're done!
